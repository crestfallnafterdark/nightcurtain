## Invariants

- `AgentModelConfig`'s single home is this contract; new code imports it from here, `runtime/agent` re-exports it type-only, and `domain/directorAgent` consumes it type-only.
- Transport receives an already-resolved `AgentModelConfig`: no default model ids, presets, or inheritance policy live here or in the adapters (those belong to MOD-17 `modelConfig`).
- Configs carry `keyId` references only — no raw secret material; credentials resolve through the injected `CredentialResolverPort`, and the factory ignores any raw `apiKey`/`encryptionKey` fields on the config object.
- `ModelConfig` is frozen by adapters after creation, with `transformPayload` as the sole payload mutation hook.
- `checkBalance` never throws on HTTP failure — it resolves to `{ available: false, error }`.
- `stream` is an `AsyncGenerator<StreamChunk, CompletionResult, void>` that returns the consolidated result from its finish path; `onChunk` mirrors every yield.
- `InferenceError` extends the native `Error` (so `catch (Error)` consumers stay compatible); the HTTP-failure paths that construct it use status-derived code `ERR_HTTP_<status>`, `status` set, and `retryable` classified by the shared 429/5xx policy (the OpenAI-compatible adapters on `stream`/`complete`/`listModels`, and Prem on `listModels`); `DeepSeekError` is the preserved alias with the same class identity (`DeepSeekError === InferenceError`).
- Abort is never converted to `InferenceError`: the OpenAI-compatible adapters hand the signal to `fetch` and let the native abort error propagate; Prem rejects an already-aborted `stream` signal with a plain `Error`, propagates its SDK error during the call, and returns the partial result when the signal aborts mid-stream.
- The paired runtime companion `index.ts` is a leaf: zero imports, and its only runtime exports are the `InferenceError` class and the `DeepSeekError` alias.

## Decisions

- `AgentModelConfig`'s single home is the MOD-15 inference contract; `runtime/agent` re-exports and `domain/directorAgent` consumes it type-only
- `CredentialResolverPort` is the ratified MOD-16 `credentialVault` port consumed by the MOD-15 factory; this contract keeps a type-only re-export of its canonical shape
- Transport performs no model fallback: the factory and providers require a fully resolved config

## API docs

### `AgentModelConfig` — interface

Canonical resolved model configuration handed to MOD-15 transport.

**Single home:** this declaration is authoritative. `runtime/agent.d.ts` re-exports it type-only; `domain/directorAgent.d.ts` consumes it type-only. Both modules' former duplicate declarations are deleted.

Invariant: the transport receives an **already-resolved** config — no default model ids, presets, or inheritance policy live in MOD-15 or here (those belong to MOD-17 `modelConfig`). Contains no raw secrets: `keyId` references a credential resolved through `CredentialResolverPort`.

#### Members

- **`index signature`** — Additional resolved vendor-specific parameters.
- **`keyId`** — Credential id resolved via `CredentialResolverPort.getCredential`.
- **`modelId`** — Concrete model identifier.
- **`providerId`** — Provider identifier (e.g. `'runware'`, `'nanogpt'`, `'deepseek'`, `'prem'`, `'custom'`).
- **`reasoningEffort`** — Reasoning budget selector for reasoning-capable models.
- **`routing`** — Provider routing preference (e.g. OpenRouter-style routing slug).
- **`serviceTier`** — Provider service-tier selector (e.g. OpenAI `flex`/`priority`).
- **`temperature`** — Sampling temperature (provider-defined range).
- **`url`** — Per-agent endpoint override consumed by the factory's `custom` (required) and `openai`/unknown-vendor branches; the `runware`, `nanogpt`, `deepseek`/`deepseek_native`, and `prem` branches ignore it and use their vendor default endpoint.

### `BalanceResult` — interface

Account balance lookup result.

Contract: `checkBalance` **never throws** on HTTP failure — it resolves to `{ available: false, error }` instead.

#### Members

- **`available`** — Whether balance information was successfully retrieved.
- **`balance`** — Remaining balance (numeric or provider-formatted value).
- **`currency`** — Currency code for `balance`.
- **`error`** — Failure description when `available` is `false`.
- **`formatted`** — Pre-formatted human-readable balance string.
- **`raw`** — Raw provider payload retained for diagnostics.

### `BaseProviderOptions` — interface

Shared construction options for provider adapters.

Credential precedence, highest first: 1. the `credentialId` resolved through the injected `vault` (`vault.getCredential`), when that lookup yields a key; 2. the explicit `apiKey`; 3. the vault's active credential for the provider id (`vault.getActiveCredential`).

The effective value is `''` when none of the three yields a non-empty key. `apiUrl` overrides the adapter's vendor endpoint default.

#### Members

- **`index signature`** — Additional adapter-specific options.
- **`apiKey`** — Pre-resolved API key.
- **`apiUrl`** — Base API URL override.
- **`credentialId`** — Credential id to resolve through the injected resolver port.
- **`headers`** — Extra headers merged into every request.
- **`id`** — Explicit provider instance id.
- **`vault`** — Injected least-privilege credential resolver, or `null` when absent.

### `CompletionOptions` — interface

Conversation message accepted by non-streaming completion transports (same message shape as StreamOptions, without `onChunk`).

#### Members

- **`messages`** — Ordered conversation history/input for the request.
- **`signal`** — Cancellation signal propagated to the underlying fetch/stream.
- **`tools`** — Tool/function JSON-schema declarations offered to the model.

### `CompletionResult` — interface

Consolidated result returned by `stream` (as the generator return value) and by ModelInterface.complete.

#### Members

- **`content`** — Full assistant text content for the turn.
- **`finishReason`** — Provider finish reason (`stop`, `tool_calls`, `length`, ...).
- **`reasoning`** — Full reasoning transcript for the turn (empty when unsupported).
- **`toolCalls`** — Tool calls requested during the turn (parsed).
- **`usage`** — Aggregate token accounting, when reported.

### `CredentialResolverPort` — interface

Canonical read-only credential resolver port (registry-listed).

Constructed as a frozen plain object via `CredentialVault.createResolverPort()` and handed to runtime/domain consumers (e.g. MOD-15 `createProvider`). Returns least-privilege projections rather than full vault entries — no writes, no enumeration, no listing.

**Ratified exception (MOD-16):** a lookup miss for a canonical provider id may lazily create and persist that canonical credential; this is the sole mutating read path, documented in the module invariants.

#### Members

- **`getActiveCredential`** — Active credential for a provider id (e.g. `'runware'`, `'deepseek'`).
- **`getCredential`** — Lookup by credential id (as referenced by `AgentModelConfig.keyId`).

### `InferenceError` — class

Unified inference transport error.

Runtime implementation lives in `index.ts`; this declaration mirrors it member-for-member. Extends the native `Error`, so `instanceof Error` and `instanceof InferenceError` both hold and `message`/`stack` behave natively; `name` is fixed to `'InferenceError'`.

#### Examples

```typescript
import { InferenceError } from './index.ts';

throw new InferenceError('Upstream rate limit exceeded', {
  code: 'ERR_HTTP_429',
  status: 429,
  details: { providerId: 'deepseek' },
  retryable: true
});
```

#### Members

- **`constructor`** — Constructs a classified inference transport error.
- **`code`** — Free-form programmatic code supplied by the caller (defaults to `'ERR_UNKNOWN'`); the HTTP-failure paths that construct this class use `'ERR_HTTP_<status>'` (OpenAI-compatible adapters, and Prem `listModels`). Abort paths never construct this class, so no sandbox code path emits `'ERR_ABORTED'`.
- **`details`** — Optional structured diagnostic context for the failure.
- **`retryable`** — Caller-supplied retry classification flag (defaults to `false`); the transport retry policy classifies independently from `status` and message heuristics.
- **`status`** — HTTP status associated with the failure, or `0` when not applicable.

### `ModelInterface` — interface

ModelInterface

An instantiated model bound to a provider and configuration. Executed directly by agents (MOD-13/9 runtime).

`stream` is an `AsyncGenerator<StreamChunk, CompletionResult, void>`: it yields incremental chunks and **returns** the consolidated CompletionResult from its finish path. `onChunk` (when supplied in StreamOptions) mirrors every yield.

#### Members

- **`complete`** — Executes a single non-streaming completion.
- **`config`** — Frozen model-bound configuration.
- **`id`** — Model identifier for this instance.
- **`provider`** — Provider that produced this model instance.
- **`stream`** — Streams a chat completion, yielding incremental chunks and returning the consolidated result. The OpenAI-compatible adapters reject iteration with an `InferenceError` on non-OK HTTP responses (`status` and status-derived `code`, plus the shared retry classification); because it extends the native `Error`, `catch (Error)` consumers stay compatible. Prem transport failures are not wrapped — its `@premai/api-sdk` errors propagate as-is. Abort is never wrapped either: it surfaces as the native fetch/SDK abort error, and the Prem adapter additionally rejects an already-aborted signal with a plain `Error` and stops early (returning the partial result) when the signal aborts mid-stream.

### `ProviderInterface` — interface

ProviderInterface

Manages provider connectivity, model provisioning, discovery, routing, and balance. Members are declared `readonly` and adapters treat instances as immutable after construction, but instances are not runtime-frozen; Prem additionally memoizes its enclave client lazily (documented in its own contract). `fetch` lives in the adapter implementations, never in this contract.

#### Members

- **`checkBalance`** — Looks up account balance; never throws on HTTP failure (see BalanceResult).
- **`createModel`** — Factory method to instantiate and configure a Model. The returned instance's `config` is frozen, and `modelId` must already be resolved — the transport applies no default.
- **`getProviders`** — Lists routable providers/endpoints for a model id, or provider names.
- **`id`** — Provider instance identifier.
- **`listModels`** — Lists models offered by this provider.

### `ProviderRoute` — interface

Routable provider endpoint returned by ProviderInterface.getProviders.

#### Members

- **`available`** — Whether the route is currently usable.
- **`contextLength`** — Context window size served by this route.
- **`cost`** — Cost indicator as reported by the route.
- **`id`** — Route/provider identifier.
- **`maxInputTokens`** — Maximum input tokens, when reported.
- **`name`** — Human-readable route name.
- **`pricing`** — Raw pricing object, when reported.
- **`quantization`** — Quantization label of the served weights.
- **`raw`** — Raw provider payload retained for diagnostics.
- **`status`** — Provider-reported route status.
- **`tps`** — Observed tokens per second, when available.

### `StreamChunk` — interface

Incremental event yielded by ModelInterface.stream.

The generator yields `text`/`reasoning`/`tool_call`/`usage` chunks as they arrive and finally returns the consolidated CompletionResult (the terminal `finish` chunk marks the transition).

#### Members

- **`content`** — Incremental text delta for `text` chunks.
- **`finishReason`** — Provider finish reason (`stop`, `tool_calls`, `length`, ...).
- **`reasoning`** — Incremental reasoning delta for `reasoning` chunks.
- **`toolCalls`** — Tool-call deltas; `args` may still be an unparsed JSON string mid-stream.
- **`type`** — Chunk discriminator (`'text' | 'reasoning' | 'tool_call' | 'usage' | 'finish'`).
- **`usage`** — Token accounting attached to `usage`/`finish` chunks.

### `StreamOptions` — interface

Conversation message accepted by streaming transports.

Content is either a plain string or an array of provider-native content parts (e.g. text/image blocks); the index signature preserves vendor extensions without widening the typed core.

#### Members

- **`messages`** — Ordered conversation history/input for the request.
- **`onChunk`** — Optional mirror callback invoked for every yielded StreamChunk.
- **`signal`** — Cancellation signal propagated to the underlying fetch/stream.
- **`tools`** — Tool/function JSON-schema declarations offered to the model.

### `ToolCall` — interface

Fully accumulated tool/function call produced by a model turn.

`args` is the parsed argument object; `rawArguments` preserves the exact streamed JSON text when a caller needs it for audit or repair.

#### Members

- **`args`** — Parsed tool argument object.
- **`id`** — Provider-assigned tool-call identifier used for result correlation.
- **`name`** — Function/tool name requested by the model.
- **`rawArguments`** — Original streamed argument JSON text, when captured.
