## Invariants

- `INV-SINGLE-SOURCE` — The catalog owns the only authoritative preset list; every read resolves from its in-memory entries, and callers receive copies instead of references.
- `INV-IMMUTABILITY` — Internal entries and their modelConfigs are frozen; listPresets/getPreset and the source port return frozen fresh copies, never internal references.
- `INV-COMPLETENESS` — Every stored entry carries a non-empty id and name, a boolean isCustom, and a modelConfig with non-empty providerId and modelId; savePreset rejects invalid input and adapter-loaded entries are dropped when invalid.
- `INV-DEFAULT-VALIDITY` — getDefaultPresetId() always names an entry present in the catalog; a missing or unknown active pointer resolves to the undeletable fallback default.
- `INV-EVENTS` — savePreset and deletePreset emit synchronously after the mutation; a preset-deleted listener observes getPreset(id) === null; listener exceptions are isolated and unsubscribe is idempotent.
- `INV-PURITY` — No ambient I/O, no import-time side effects, deterministic outputs; persistence flows only through the injected adapter, whose failures never propagate to callers.
- `INV-NO-KEYID` — Catalog entries carry no credential material; the explicit credential-shaped fields keyId, apiKey, and encryptionKey are stripped from every ingested modelConfig, on seed, on adapter load, and on save.

## Decisions

- Ingested modelConfigs are normalized by stripping the explicit credential-field set keyId/apiKey/encryptionKey (exact-name matching only, never patterns) so entries expose only credential-free PresetModelConfig fields; resolution re-attaches the provider-active credential at turn start
- storage.save receives the full catalog projection after every mutation; adapter load overlays entries by id, appends unknown ids, and load/save failures degrade to the in-memory catalog
- The seed entry matching getDefaultModelConfig() is the undeletable fallback default; deletePreset rejects it, deletePreset of an unknown id is a no-op, and stale active pointers resolve to the fallback without being rewritten
- setActivePresetId accepts only existing catalog ids and swallows pointer-write failures; the source port's subscribe delegates to the catalog's isolated listener set

## API docs

### `createPresetCatalog` — function

Creates the preset catalog service.

Seeds the catalog from `PRESET_MODELS`, overlays adapter-loaded entries by id, and returns the CRUD/events/port surface. The returned object is frozen; all reads hand out frozen copies of frozen internal entries.

#### Parameters

- `options` — Injected storage adapter and active-pointer closures

#### Returns

The frozen catalog service

### `ModelPreset` — interface

One catalog entry: an official seed preset or a user-authored custom preset.

#### Members

- **`id`** — Catalog key: an official provider id or a `preset_custom_*` id.
- **`isCustom`** — `true` for user-authored entries, `false` for official seed entries.
- **`modelConfig`** — Provider/model selection plus tuning; never carries `keyId` or secret material.
- **`name`** — Display name shown by catalog consumers.

### `ModelPresetSourcePort` — interface

Read-only runtime projection of the catalog, built by `presetCatalog.createPresetSourcePort()` and injected by the composition root for turn-start model resolution and catalog-change subscription.

The projection is a frozen plain object: every read resolves from the live catalog and hands out frozen copies, so consumers never observe internal references or mutate catalog state. `subscribe` delivers synchronous change events with isolated listener exceptions and an idempotent unsubscribe.

#### Members

- **`getDefaultPresetId`** — Resolves the active global preset id.
- **`getPreset`** — Resolves one preset by id.
- **`subscribe`** — Subscribes to synchronous catalog change notifications.

### `PresetCatalog` — interface

Catalog service returned by `presetCatalog.createPresetCatalog()`.

#### Members

- **`createPresetSourcePort`** — Builds the frozen runtime projection of this catalog.
- **`deletePreset`** — Deletes an entry and publishes `preset-deleted`.
- **`getPreset`** — Frozen copy of one entry, or `null` when unknown.
- **`listPresets`** — Frozen copies of every entry, in catalog order.
- **`savePreset`** — Creates or replaces an entry and publishes `preset-updated`.
- **`setActivePresetId`** — Sets the active global preset id; the id must name a catalog entry.
- **`subscribe`** — Subscribes to catalog changes; returns an idempotent unsubscribe.

### `PresetCatalogOptions` — interface

Construction options for `presetCatalog.createPresetCatalog()`.

#### Members

- **`getActivePresetId`** — Reads the active global preset id from the composition root.
- **`setActivePresetId`** — Persists the active global preset id through the composition root.
- **`storage`** — Injected persistence adapter for the catalog entries.

### `PresetCatalogStorageAdapter` — interface

Persistence seam supplied by the composition root.

#### Members

- **`load`** — Returns the persisted catalog entries; unknown or invalid values are dropped.
- **`save`** — Receives the full catalog projection after every mutation.

### `PresetChangeEvent` — interface

Synchronous notification published after a catalog mutation.

#### Members

- **`presetId`** — Id of the saved or deleted entry.
- **`type`** — Mutation kind.

### `PresetChangeType` — type alias

Catalog mutation kind carried by PresetChangeEvent.

### `PresetModelConfig` — type alias

A preset's model configuration: the canonical `AgentModelConfig` shape minus the `keyId` credential reference. A preset never pins a credential; the effective config re-attaches the provider-active credential at resolution.
